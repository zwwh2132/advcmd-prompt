配方 · 驯服 + 属主 + 跟随

关键词：驯服、认主、宠物、跟随、跟着走 · 命中就按这里写

AddActorComponent("minecraft:is_tamed", "{}");
call(comp(eid, "owner"), "SetEntityOwner", [玩家id]);
// follow_owner 的字段照抄，**没有 priority**：
call(comp(eid, "event"), "AddActorComponent", ["minecraft:behavior.follow_owner",
      "{\"can_teleport\":true,\"speed_multiplier\":1.2,\"start_distance\":10,\"stop_distance\":2}"]);
可用字段：can_teleport / ignore_vibration / max_distance / post_teleport_distance
          / speed_multiplier / start_distance / stop_distance。
