【0.1】探测脚本怎么写才跑得起来（照这个来）
· 只探下面列过的组件种类，别猜名字：comp(id,"entity") 会当场报错，整段回调停住。
· 一项一段、前面先 log 标题；一次探 2~3 项就够。
· 判断有没有某方法：index_of(methods(c), "方法名") >= 0；
  不要写 typeof(名字)——未定义的名字直接报错。
· 例：on start { var c = comp(players()[0], "event"); var ms = methods(c);
  for (var i = 0; i < len(ms); i++) { log(ms[i]); } }
· 报错只中止这一次回调，方块不受影响；把面板「输出」整段贴回来。

脚本挂在这个方块上：方块收到事件就执行对应的一段；顶层语句开局跑一次，变量即全局。

【1】语法（C 风格子集）
· 语句以分号结尾；var x = 1;  const N = 10;
· if (x > 0) { } else if (x < 0) { } else { }   while (x < 10) { }
· for (var i = 0; i < n; i++) { }   for (var k in 列表) { }（k 是元素本身）
· break;  continue;  return 值;
· int add(int a, int b) { return a + b; }（类型只是标注，不会强校验；玩家/实体 id 是字符串）
· 值：数字 / 字符串 "文本" / true / false / null / [1,2] / { hp: 2.0 }
· 注释：// 行注释   /* 块注释 */
· 下标和点号都能读写：a[0]、a["键"]、a.键；也能 a[0] = 9、a.键 = 9
    键是中文时只能写 a["血量"]，点号只认英文（中文不叫名字）
· 运算 + - * / % && || ! == != < <= > >=；三元 条件 ? 甲 : 乙；i++、i += 2 都能用
· **整数相除取整**：7 / 2 得 3，要小数写 7.0 / 2；文本 + 数字自动变文本
· 没有：import、类、闭包/lambda、try、中文标识符、文本的 .length（用 len()）
· 自带：len() rand(小,大) pick(列表) at(列表,下标) str() num() typeof()
  abs() min() max() clamp(值,小,大) floor() ceil() round()
  表 set(t,k,v) has(t,k) del(t,k) keys(t)；列表 push pop set_at remove_at index_of
【2】事件
· on start { }        方块第一次载入脚本时执行一次
· on run { }          收到一次触发：红石上升沿，或保持运行模式的第一次
· on tick(n) { }      每 n tick 一次（20 tick = 1 秒）
· on stop { }         红石信号消失时执行一次（清理 on run 生成的东西）
· 同一种事件只能写一次：写两个 on tick 会被后者覆盖
· 定时器：after(秒, 函数名) 一次 / every(秒, 函数名) 周期 / cancel(句柄) 取消；
  函数名写成字符串，比如 after(3, "boom")，函数要自己写 int boom() { }。
· 常用引擎事件（名字必须一字不差，拿不准就别说自己知道）：
    ServerBlockUseEvent               玩家右键方块（x y z blockName playerId itemDict dimensionId）
    ServerItemUseOnEvent              手持物品右键方块（entityId itemDict x y z blockName dimensionId）
    ServerPlayerTryDestroyBlockEvent  玩家破坏方块（x y z fullName playerId dimensionId）
    PlayerDoInteractServerEvent       玩家与生物交互（playerId itemDict interactEntityId）
· 想响应引擎事件用 listen("事件名", "函数名")，
  处理函数收一张表（与 ModSDK 的 py 写法一致）：
    int on_use(table args) { var x = get(args, "x"); }

【3】两个完整例子（照这个结构和风格写）
例 1：每 60 秒提醒一次，5 秒后清掉方块 60 格内的掉落物
every(60, "announce");

int announce() {
    say("掉落物将在 5 秒后清理", 999999);
    after(5, "clean");
    return 1;
}

int clean() {
    command("kill @e[type=minecraft:item,r=60]");
    return 1;
}

例 2：通电后每 3 秒刷一只僵尸，场上最多 5 只；断电时清干净
var ids = [];
var h = 0;

on run {
    cancel(h);
    ids = [];
    h = every(3, "spawn_one");
}

on stop {
    cancel(h);
    h = 0;
    for (var i = 0; i < len(ids); i++) { kill(ids[i]); }
    ids = [];
}

int spawn_one() {
    var n = 0;
    for (var i = 0; i < len(ids); i++) {
        if (alive(ids[i]) == 1) { n = n + 1; }
    }
    if (n >= 5) { return 0; }
    push(ids, spawn_id("minecraft:zombie", 6));
    return 1;
}
【4】接口（全部，都用得上）
  log(文本)  写进面板的「输出」区
  say(文本, 半径)  附近玩家聊天栏播报
  pos()  方块坐标（取分量写 pos()[0]）
  pos_x()  方块坐标 X
  pos_y()  方块坐标 Y
  pos_z()  方块坐标 Z
  players()  所有玩家 id
  near(半径)  方块附近的玩家 id
  spawn(类型, 数量, 半径)  周围刷怪，返回实际数量
  spawn_id(类型, 半径)  刷一只，返回它的 id
  alive(实体id)  1=存活 0=已消失
  kill(实体id)  销毁实体
  kill_near(半径, 类型)  清掉方块附近的非玩家实体
  give(玩家id, 物品id, 数量)
  tp(实体id, x, y, z)
  buff(实体id, 效果, 秒, 等级)
  set_block(x, y, z, 方块id)
  at(列表, 下标)  取元素，越界给 null
  dist(实体a, 实体b)  两点距离
  comp(实体id, 种类)  拿组件对象；种类填 pos/attr/rot/effect/item/block/event/type/name/hurt/model/particle/sound/command/player/owner/action/control/physx/game 等，填错会报可用列表
  call(对象, 方法名, [参数])  第一参必须是 comp()/sys() 拿到的对象，不能是实体 id
  methods(对象)  列出可调方法
  enum("AttrType.HEALTH")  取引擎枚举
  sys(命名空间, 系统名)  拿系统对象
  listen("事件名", "处理函数名")  订阅引擎事件
  unlisten(事件名)  退订；不带参数=全退
  get(表, "键", 默认值)  取键值，可带默认值
  command(指令)  以方块为执行点，受存档指令开关影响
  after(秒, 函数名)  过一会儿执行一次，返回句柄
  every(秒, 函数名)  每隔一会儿执行，返回句柄
  cancel(句柄)  取消定时器

【5】怎么选手段（组件接口最稳，其次动态调用，最后指令）
· 组件接口 spawn/kill_near/give/tp/buff/set_block：不受指令开关影响，优先用
· 动态调用 comp(实体id,种类) → call(对象,"方法名",[参数])；枚举用 enum("AttrType.HEALTH")
· 给生物加行为组件（能飞、会射、护主都靠这个）；第二个参数是组件名，第三个是它的 JSON：
    call(comp(id, "event"), "AddActorComponent", ["minecraft:shooter", "<组件JSON>"])
  ⚠️ JSON 里的双引号**必须转义**，否则整段脚本编不过：
    ["minecraft:shooter", "{\"def\":\"minecraft:small_fireball\"}"]
· 对象与数据要分清：comp() 返回对象只能 call()；表/列表才用 get() 和下标
    取主手物品：var it = call(comp(pid, "item"), "GetPlayerItem", [2, 0]); 再 it["itemName"]
· 读方块：var info = call(comp(0, "block"), "GetBlockNew", [[x, y, z], 维度])
    维度取事件的 dimensionId；comp(0, "block") 与 comp(0, "game") 第一参随便填
· 驯服 = 加 minecraft:is_tamed（未实机验证，跑不通就先探测）；属主 = call(comp(实体, "owner"), "SetEntityOwner", [玩家id])
· 指令 command("…") 以方块为执行点；选择器只认 r=，自定义实体写全 id
